# Игра в окне

## Запуск

Положить рядом два файла и запустить:

```
sim.py     движок
play.py    окно и оркестратор
```

```
python3 play.py
```

Откроется `http://127.0.0.1:8765`. Зависимостей нет, только Python 3.

## Как играть

1. Выбрать провайдера и модель.
2. Написать сценарий свободным текстом: «попаданец в 1052 год, окраины
   Новгорода, при мне только то, что было в карманах».
3. Нажать «Начать игру».

Мир, люди, фракции, счётчики и снаряжение сгенерируются, пройдут валидацию,
и начнётся партия. Дальше — жать варианты или писать своё действие.
У OpenAI и LM Studio генерация замысла идёт со structured output
(`response_format` + JSON Schema): `skills` — объект чисел, не список;
`difficulty`/`power`/`disposition` — числа. Схема не заменяет `validate()`.

## Провайдеры

| Выбор | Куда идёт | Ключ |
|---|---|---|
| Ollama | `127.0.0.1:11434` | не нужен |
| LM Studio / llama.cpp | `127.0.0.1:1234/v1` | не нужен |
| OpenAI-совместимый | api.openai.com или свой адрес | нужен |
| Anthropic | api.anthropic.com | нужен |

Поле «свой адрес» переопределяет URL — сюда можно вписать любой
OpenAI-совместимый сервер: vLLM, TGI, прокси.

## Что происходит на каждом ходу

1. **Разбор намерения.** Модель при температуре 0.15 превращает твоё
   действие в параметры: сколько минут, какая нагрузка, какие проверки.
   Возвращает строгий JSON.
2. **Считает Python.** Время по сегментам, среда, потребности, броски,
   раны, доступ к вещам, NPC, фракции, слухи, счётчики.
3. **Проза.** Модель при температуре 0.9 пишет сцену **по симптомам**,
   а не по числам.

Модель второго вызова физически не видит ни одной шкалы: ей передаются
только фразы вроде «дрожь прекратилась, пришло тепло» и «получилось, но
что-то потеряно навсегда». Проболтать число неоткуда, подогнать механику
под красивый текст — тоже.

## Состояние

Живёт в `play_state.json` рядом. В браузер не попадает никогда.
Файл можно смотреть, сохранять, откатывать — это обычный мир движка,
с ним работают все команды `sim.py`.

## Если что-то идёт не так

- «модель недоступна» — не запущен Ollama/LM Studio или неверный адрес.
- Мир не собрался за три попытки — модель слабая для генерации.
  Возьми модель покрупнее для старта, играть можно и мелкой.
- Проверить сам движок: `python3 sim.py selftest` → «провалено 0».
