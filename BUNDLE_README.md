# Сборка для любой ЛЛМ

## Если агент умеет исполнять код — два файла

```
sim.py                 весь движок в одном файле, без зависимостей
AGENT_INSTRUCTIONS.md  как им пользоваться (даётся агенту как системный промпт)
```

Плюс один файл состояния — `state.json`. Всё.

Проверка на месте: `python3 sim.py selftest` → должно быть «провалено 0».

### Команды

```
sim.py selftest                    доказать сборку числами
sim.py new --brief b.json --out state.json    сгенерировать мир
sim.py check --state state.json    проверить мир
sim.py checkrules                  проверить набор правил
sim.py look --window 5             осмотреться, время не тратится
sim.py act --minutes 40 --activity 1 --check "perception:20:осмотр::восприятие"
sim.py fight --foe "имя:45:10:0" --foe "второй:30:0:4"
sim.py treat --supplies 20         обработать рану
sim.py compact                     уплотнить канон (раз в 40-50 ходов)
sim.py snapshot --tag имя | restore --file путь
```

`SIM_STATE` задаёт файл состояния, `SIM_RULES` — внешний набор правил
(по умолчанию встроен).

## Если агент кода НЕ исполняет

Тогда `sim.py` бесполезен: прочитать его модель может, выполнить — нет.
Нужен текстовый документ с ядром правил, и точность будет заметно ниже:
модель не умеет держать в уме барометрическую формулу и начинает
сочинять числа примерно через 10-15 ходов.

## Что внутри sim.py

Собран из пяти модулей и набора правил: физика среды и вещества,
разрешение действий, снаряжение с временем доступа, слой общества
(слухи, фракции, стычки), генератор миров с валидатором, самотест.

Пересборка после правок исходников: `python3 build_bundle.py`.
